# GTA 100% Tracker — releases

Téléchargements de **GTA 100% Tracker**, un suivi de complétion 100 % pour GTA III, Vice City, San Andreas,
Liberty City Stories, Vice City Stories, GTA IV et GTA V (histoire) : checklists, cartes interactives,
mode chasse avec overlay.

**Télécharger :** [dernière version](../../releases/latest) → `GTATracker.exe` (Windows 10/11, WebView2).
Pas d'installation : lancer l'exe. La progression est enregistrée dans `%APPDATA%\GTATracker`.

**Mises à jour :** l'application vérifie ce dépôt au démarrage et propose d'installer la nouvelle version
(empreinte SHA-256 vérifiée avant remplacement). Désactivable dans *Mises à jour*.

Ce dépôt ne contient que les exécutables publiés.
